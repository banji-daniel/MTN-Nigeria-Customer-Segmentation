# MTN Nigeria Customer Segmentation Dashboard

## Project Overview

This project applies customer segmentation to help Nigerian SMEs move from guesswork to data-driven decisions. Using an MTN Nigeria customer dataset, the data was cleaned and analyzed in Power BI to group customers into four segments (Regular, Loyal High-Value, At-Risk, and New High-Value) based on spending, tenure and engagement. An interactive dashboard highlights key metrics such as revenue, churn rate, customer distribution, regional patterns and age groups, enabling business owners to identify high-value customers, detect churn risks and make more informed marketing and retention decisions.

## Business Problem

Many Nigerian SMEs rely on assumptions rather than customer data when making marketing and retention decisions. This project demonstrates how customer segmentation can help businesses better understand their customers and develop targeted strategies.

## Key Insights

- Regular Customers make up the largest customer segment.
- Customer churn rate is 29.4%.
- Customer segments vary across states.
- Customers aged 56+ represent the largest age group.
- Revenue patterns help identify high-value customer groups.
